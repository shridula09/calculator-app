# Calculator App

A beginner-friendly calculator web app built with HTML, CSS, and JavaScript.

## Features
- Addition, subtraction, multiplication, division
- Decimal numbers
- Percentage
- Sign toggle (+/-)
- Clear and backspace
- Keyboard support
- Calculation history
- Responsive design
- Error handling for division by zero
- No external libraries or installation required

## Project structure
```text
calculator_app/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## How to run

### Method 1: Open directly
1. Extract the ZIP.
2. Open the `index.html` file in Chrome, Edge, or Firefox.
3. Start using the calculator.

### Method 2: VS Code
1. Install Visual Studio Code.
2. Open the extracted `calculator_app` folder.
3. Install the **Live Server** extension if you want automatic browser refresh.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

No Python, Node.js, npm, database, or backend is required.

## Keyboard controls
- `0-9` → numbers
- `+`, `-`, `*`, `/` → operators
- `Enter` or `=` → calculate
- `Backspace` → delete one character
- `Escape` → clear
- `.` → decimal point
- `%` → percentage
